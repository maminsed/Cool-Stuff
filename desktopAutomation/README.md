# Desktop Automation

A simple Python script that automates opening Chrome, navigating to Gmail, composing an email, and sending it using PyAutoGUI.

## Setup

1. Clone or download this repository
2. Install the required packages:

```bash
pip install -r requirements.txt
```

## Usage

Run the script:

```bash
python main.py
```

The script will:
- Open Chrome
- Navigate to Gmail
- Compose an email to the predefined address
- Send the email

## Requirements

See `requirements.txt` for the full list of dependencies.

Note: Make sure you have Tesseract OCR installed and configured for pytesseract to work properly.
